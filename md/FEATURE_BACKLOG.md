# Бэклог игровых фич (приоритет для Medieval Society Daily)

**Правило:** агент берёт задачу **сверху списка**, если не помечена «заблокировано». После реализации — переносит в `TECHNICAL_DEBT.md` (сделано) и дописывает новую идею вниз.

Обновлено: **2026-09-07** — смена стратегии после цикла v2.3–v3.9 (только инспектор + smoke).

---

## P0 — видно на карте / в поведении

| # | Фича | Зачем | Файлы (ориентир) |
|---|------|-------|------------------|
| 1 | **Похороны / кладбище** | Трупы лежат на карте вечно; только обрезка памяти при >220 агентах | `behavior.ts`, `renderer.ts`, `map.ts`, `housing.ts`, новый `burial.ts` |

| 3 | **Колодец** | Здание у воды: меньше застреваний, очередь за водой | `map.ts`, `resources.ts`, `behavior.ts` |
| 4 | **Пекарня / сушка мяса** | Переработка излишков амбара → запас на зиму | `craft.ts`, `map.ts`, `jobs.ts` |

## Не брать в ежедневный релиз

- Новый тренд в `analyzeDayHistoryTrend` без игровой механики.
- Очередной smoke +720 дней (20160 → 20880 → …) — уже есть тесты до 20160д; расширять **раз в 2 недели максимум**.
- Дублирование changelog на GitHub Pages.
