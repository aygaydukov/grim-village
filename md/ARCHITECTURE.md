# Архитектура

## Принцип

Симуляция не знает про Canvas. Рендер читает состояние мира и рисует. Позже можно заменить `src/render` на PixiJS или спрайты без переписывания поведения агентов.

```
src/
  main.ts          — игровой цикл, ввод, связь слоёв
  sim/             — мир, карта, агенты, поведение
  render/          — камера, палитра, отрисовка
  input/           — клавиатура
  ui/              — HUD / инспектор (DOM)
```

## Тик мира

- ~30 тиков/сек при скорости ×1
- `dayLength = 1200` тиков ≈ один игровой день
- Ночь усиливает холод/усталость, еда почти не растёт

## Агенты

Нужды: `hunger`, `energy`.  
Семья: `spouseId`, `motherId`, `fatherId`.  
Переноска: `carriedFood` → амбар.

Состояния: wander, seekFood, eat, seekRest, sleep, seekMate, court, seekGather, gather, deposit, idle.

Смерть: голод, холод/истощение ночью, старость.  
Рождение: ухаживание → супруги → беременность → ребёнок с родителями.

## Карта

Процедурная (seed): трава, грязь, лес, вода, хижины, **амбар** в центре.  
Дикая еда растёт; жители носят её в амбар и едят со склада в голод.

## Профессии и задачи

Модуль `src/sim/jobs.ts`:
- профессии: child / gatherer / laborer / keeper / elder
- задачи: idle, patrol, returnHome, gather, deposit, eat, rest, social, play
- leash: агент не уходит далеко от дома (или амбара для сборщика/сторожа)

Приоритет поведения: нужды → возврат на участок → работа по профессии.
Бесцельного бродяжничества по карте нет.

## Дальнейший апгрейд графики

1. Оставить `World` / `Agent` как есть.
2. Подменить `renderWorld` (Pixi / спрайт-атлас).
3. Камеру и `screenToWorld` сохранить или адаптировать один раз.
