# План развития «Мрачной деревни»

Обновлено: **2026-07-25** (ежедневный прогон Medieval Society Daily, вечер).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| Именованные события в летописи | **Берём** | Приоритет №2; данные `dayHistory` обогащаются без новых подсистем. |
| Сохранение/загрузка JSON | **Берём** | Приоритет №1; `persist.ts` + localStorage, PRNG state для точного продолжения. |
| Неурожай / эпидемии | **Отложить** | Сезон уже даёт вариативность; двойной шок рискован для стабильности. |
| Pathfinding A* | **Отложить** | Стабильность достаточна; большой diff. |
| Постройка хижин | **Отложить** | Нужна политика земли и ресурсов. |
| Государство / налог | **Отложить** | После событий летописи и save/load — иначе некуда писать историю. |
| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона. |

## Следующие циклы (приоритет)

1. **Неурожай** — редкий сезонный шок поверх `seasonFoodFactor` (осень/зима, низкий амбар).
2. **Постройка хижин** — батраки расширяют поселение при перенаселении.
3. **Pathfinding** — меньше застреваний у воды.
4. **Государство / налог** — доля урожая «старосте», очередь на еду.
5. **Выбор seed и размер карты из UI** — после save/load уже есть seed в сохранении.
6. **Ремесло** — кроме склада еды.

## Метрики стабильности (10 дней)

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.
