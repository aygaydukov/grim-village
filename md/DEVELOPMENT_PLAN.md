# План развития «Мрачной деревни»

Обновлено: **2026-07-24** (ежедневный прогон Medieval Society Daily).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| Динамический рынок труда | **Берём** | Запасы амбара напрямую влияют на выживание; квоты профессий уже есть, но не пересчитывались по нужде деревни. |
| Фамилии / роды | **Берём** | Малый diff, усиливает «историю людей» и UI без новых систем. |
| Дневная история (`dayHistory`) | **Берём** | База для мониторинга, автотестов и будущей летописи. |
| Headless-модуляция 10 дней | **Берём** | Обязательный критерий стабильности каждого прогона. |
| Исправление воды в центре + hunger/leash | **Берём** | Критический баг: 9+ смертей на 2–3 день из‑за недоступного амбара. |
| Сохранение/загрузка | **Отложить** | Инфраструктура есть (`World`), но UI и сериализация — отдельный спринт. |
| Pathfinding A* | **Отложить** | Текущее движение достаточно для стабильности; A* — большой diff. |
| Болезни / неурожай | **Отложить** | Нужен баланс после трудового рынка, иначе двойной шок. |
| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона общества. |
| Миграция при перенаселении | **Отложить** | SOFT_POP_CAP уже смягчает рост; миграция — отдельная политика. |
| Ремесло (кроме еды) | **Отложить** | Сначала стабилизировать продовольственный контур. |
| Юнит-тесты в `tests/` | **Берём (минимум)** | Smoke-тест стабильности на нескольких seed. |

## Следующие циклы (приоритет)

1. **Летопись деревни** — UI по `dayHistory`, события (рождения, голод, смена профессий).
2. **Сохранение мира** — JSON snapshot + seed в localStorage.
3. **Неурожай / зима** — сезонный множитель регена еды.
4. **Постройка хижин** — батраки расширяют поселение при перенаселении.
5. **Pathfinding** — меньше застреваний у воды, быстрее сбор.
6. **Государство / налог** — доля урожая «старосте», очередь на еду.

## Метрики стабильности (10 дней)

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.
