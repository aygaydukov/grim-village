# План развития «Мрачной деревни»

Обновлено: **2026-07-26** (ежедневный прогон Medieval Society Daily, v0.4.0).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| Миграция при перенаселении | **Сделано (v0.4.0)** | Семьи уходят при критическом дефиците жилья + голод/пустой амбар; снимает давление без массовой смерти. |
| Эпидемии | **Отложить** | Миграция + неурожай уже дают вариативность; двойной шок рискован для 10-дневной стабильности. |
| Политика старосты | **Берём следующим** | Казна есть — решения о налоге и приоритете стройки vs амбара добавят глубину. |
| Path smoothing A* | **Отложить** | Pathfinding работает; сглаживание — косметика движения. |
| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Выбор seed из UI | **Отложить** | Save/load уже хранит seed. |
| Ремесло (кроме еды) | **Отложить** | Нужна стабильная казна и торговля — после политики старосты. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона. |

## Следующие циклы (приоритет)

1. **Политика старосты** — решения о налоге, приоритете стройки vs амбара.
2. **Эпидемии** — редкий шок смертности (отдельно от неурожая).
3. **Выбор seed и размер карты из UI**.
4. **Ремесло** — кроме склада еды; связь с казной.
5. **Path smoothing** — сглаживание углов A* для более естественного движения.
6. **Иммиграция** — редкий приток беженцев при пустой деревне (симметрия к исходу).

## Метрики стабильности (10 дней)

> 10 игровых дней ≈ **0.014 года** на новой шкале (это короткий smoke-прогон баланса еды/смертей, не поколение).
> Полный год = 720 игровых дней; 3 года ≈ 1 реальные сутки при ×1.

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.

### Долгий прогон (100 дней)

Smoke-тест CI — 10 дней. На 100 днях часть seed даёт постепенный спад населения (смерти без рождений в ранние годы) — **известный дисбаланс**, не регрессия v0.4.0. Следующий цикл: смягчить смертность стариков / поднять рождаемость при полном амбаре.
