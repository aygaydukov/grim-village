# План развития «Мрачной деревни»

Обновлено: **2026-07-25** (ежедневный прогон Medieval Society Daily).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| UI летописи по `dayHistory` | **Берём** | Приоритет №1 прошлого цикла; данные уже есть, нужен только вывод и события дня. |
| Расширение снимков (дельты, сезон) | **Берём** | Малый diff, даёт содержательные записи летописи без новых подсистем. |
| Мягкий сезонный regen еды | **Берём (осторожно)** | Множители 0.78–1.15; smoke-тесты на 5 seed проходят. |
| Сохранение/загрузка | **Отложить** | Отдельный спринт: сериализация `World` + UI. |
| Неурожай / эпидемии | **Отложить** | Сезон уже даёт вариативность; двойной шок рискован. |
| Pathfinding A* | **Отложить** | Стабильность достаточна; большой diff. |
| Постройка хижин | **Отложить** | Нужна политика земли и ресурсов. |
| Государство / налог | **Отложить** | После летописи и save/load — иначе некуда писать историю. |
| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона. |

## Следующие циклы (приоритет)

1. **Сохранение мира** — JSON snapshot + seed в localStorage.
2. **События летописи** — имена умерших/родившихся, смена профессий (не только счётчики).
3. **Неурожай** — редкий сезонный шок поверх `seasonFoodFactor`.
4. **Постройка хижин** — батраки расширяют поселение при перенаселении.
5. **Pathfinding** — меньше застреваний у воды.
6. **Государство / налог** — доля урожая «старосте», очередь на еду.

## Метрики стабильности (10 дней)

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.
