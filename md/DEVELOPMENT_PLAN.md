# План развития «Мрачной деревни»

Обновлено: **2026-07-26** (ежедневный прогон Medieval Society Daily, v0.5.0).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| Политика старосты | **Сделано (v0.5.0)** | Четыре режима: сбалансированная, стройка, запасы, поддержка; десятина 5–15%; автовыбор по голоду/амбару/жилью. |
| Эпидемии | **Отложить** | Политика + миграция + неурожай уже дают вариативность; двойной шок рискован для 10-дневной стабильности. |
| Иммиграция (симметрия исходу) | **Берём следующим** | Редкий приток беженцев при пустой деревне — логичное продолжение migration.ts. |
| Path smoothing A* | **Отложить** | Pathfinding работает; сглаживание — косметика движения. |
| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Выбор seed из UI | **Отложить** | Headless daemon хранит seed на сервере. |
| Ремесло (кроме еды) | **Отложить** | Нужна стабильная казна и торговля — после иммиграции. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона. |
| 100-дневный баланс рождений | **Частично** | Поднята рождаемость при полном амбаре; беременность 540 дн. — рождения в 100-дн. smoke невозможны без укорочения цикла. |

## Следующие циклы (приоритет)

1. **Иммиграция** — редкий приток беженцев при низком населении (симметрия к исходу).
2. **Эпидемии** — редкий шок смертности (отдельно от неурожая).
3. **Выбор seed и размер карты из UI**.
4. **Ремесло** — кроме склада еды; связь с казной.
5. **Path smoothing** — сглаживание углов A* для более естественного движения.
6. **Укороченный smoke-прогон беременности** — отдельный тестовый режим или параметр для CI 100-дн.

## Метрики стабильности (10 дней)

> 10 игровых дней ≈ **0.014 года** на новой шкале (это короткий smoke-прогон баланса еды/смертей, не поколение).
> Полный год = 720 игровых дней; 3 года ≈ 1 реальные сутки при ×1.

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.

### Долгий прогон (100 дней)

Smoke-тест CI — 10 дней. На 100 днях все seed дают спад без рождений: **беременность = 540 игровых дней** — структурный дисбаланс, не регрессия v0.5.0. Следующий цикл: иммиграция и/или отдельный долгий smoke с укороченной беременностью для CI.
