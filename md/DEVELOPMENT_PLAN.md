# План развития «Мрачной деревни»

Обновлено: **2026-07-31** (ежедневный прогон Medieval Society Daily, v1.1.0).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| CI-режим 100 дней | **Сделано (v1.1.0)** | Укороченная беременность (45 дн.), `npm run simulate:ci`, тест в `stability.test.ts`. Рождения проверяются. |
| Гарантированный сезонный караван | **Сделано (v1.1.0)** | Если за 12 дней до конца сезона караван не приходил — принудительный визит. |
| Тепло от полного амбара | **Сделано (v1.1.0)** | `barnWarmthMultiplier` — меньше ночного холода при запасах ≥ 55 мер. |
| Расширенная торговля караванов | **Сделано (v1.0.0)** | Соль, железо, сезонные маршруты. |
| 100-дневный баланс (обычный режим) | **Отложить** | 19 смертей / 15 живых (seed=2026) — лучше, чем 23/12, но порог smoke 40% всё ещё не проходит. Рождений нет (беременность 540 дн.). |
| Эпидемии | **Отложить** | Демография уже вариативна; двойной шок смертности рискован. |

| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Выбор seed из UI | **Отложить** | Headless daemon хранит seed на сервере. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона. |

## Следующие циклы (приоритет)

1. **Баланс 100-дневного обычного режима** — снизить смертность без CI (ночной отдых, приоритет еды старикам).
2. **Эпидемии** — редкий шок смертности (отдельно от неурожая).
3. **Выбор seed и размер карты из UI**.
4. **Path smoothing** — сглаживание углов A*.
5. **Спрайты** — замена силуэтов.

## Метрики стабильности (10 дней)

> 10 игровых дней ≈ **0.014 года** на новой шкале (короткий smoke-прогон баланса еды/смертей).
> Полный год = 720 игровых дней; 3 года ≈ 1 реальные сутки при ×1.

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.

### Долгий прогон (100 дней)

| Режим | seed=2026 | Результат |
|-------|-----------|-----------|
| Обычный | 15 живых, 19 смертей, 0 рождений | Амбар 93, голод ср. 40.1 — еда в норме, смерти от холода/голода |
| CI (`--ci`) | 13 живых, 22 смерти, **1 рождение** | Стабильно по CI-порогам; демография проверяется |

**Идеи для улучшения обычного 100-дн.:** приоритет сна у истощённых; снижение NIGHT_COLD при полном амбаре + соли; ранний караван соли в первый сезон.

### Диагностика нестабильности

- Много смертей от **голода/холода** + пополнение **беженцами** → внутренний цикл слаб (см. инспектор «Деревня»).
- Деревня **пуста**, миграция ещё не сработала → фатал, нужен drop и анализ механик.
- Основные причины смерти в длинных прогонах: холод и истощение (ночь + низкая энергия), голод — на втором месте.
