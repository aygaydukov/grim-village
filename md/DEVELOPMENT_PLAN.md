# План развития «Мрачной деревни»

Обновлено: **2026-07-25** (ежедневный прогон Medieval Society Daily, ночь).

## Цель

Устойчивое, саморазвивающееся средневековое общество: еда → люди → труд → запасы → снова еда (замкнутый цикл с нелинейным равновесием, см. Malthusian feedback в симуляциях agrarian societies).

## Оценка целесообразности (этот цикл)

| Задача | Решение | Обоснование |
|--------|---------|-------------|
| Неурожай (сезонный шок) | **Берём** | Приоритет №1; редкий шок в осень/зиму при низком амбаре, без двойного удара с сезоном. |
| Постройка хижин | **Отложить** | Нужна политика земли и ресурсов; после шоков — чтобы был смысл расширяться. |
| Pathfinding A* | **Отложить** | Стабильность достаточна; большой diff. |
| Государство / налог | **Отложить** | После постройки хижин — иначе некому собирать налог. |
| Эпидемии | **Отложить** | Неурожай уже даёт вариативность; двойной шок рискован. |
| Спрайты / PixiJS | **Отложить** | Графика не блокирует симуляцию. |
| Выбор seed из UI | **Отложить** | Save/load уже хранит seed. |
| Звук | **Отказ на сейчас** | Нет ценности для автоматического прогона. |

## Следующие циклы (приоритет)

1. **Постройка хижин** — батраки расширяют поселение при перенаселении.
2. **Pathfinding** — меньше застреваний у воды.
3. **Государство / налог** — доля урожая «старосте», очередь на еду.
4. **Эпидемии** — редкий шок смертности (отдельно от неурожая).
5. **Выбор seed и размер карты из UI** — после save/load уже есть seed в сохранении.
6. **Ремесло** — кроме склада еды.

## Метрики стабильности (10 дней)

- Живых ≥ 50% от старта (≥ 11 при 22).
- Смертей ≤ 40% от старта за прогон.
- Амбар ≥ 8 мер к концу.
- Средний голод < 78.
- Население не вымерло.

Команда проверки: `npm run simulate` и `npm test`.
